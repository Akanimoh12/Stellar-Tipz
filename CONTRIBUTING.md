# Contributing to Stellar Tipz

Thanks for helping improve Stellar Tipz. This page is the short version, so GitHub can show it
when you open an issue or a pull request. The full guide is
[`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md): read it before your first pull request.

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Before you start

- **Found a security problem?** Do not open a public issue. Follow [`SECURITY.md`](SECURITY.md).
- **Bug or idea?** Search the existing issues first, then open one using an issue template.
- **Larger change?** Open an issue to discuss it before you write code.
- **Setting up locally?** See [`docs/SETUP.md`](docs/SETUP.md).

## The short workflow

1. Fork the repository and create a branch from the default branch.
2. Name the branch by the kind of change: `feature/…`, `fix/…`, `chore/…` or `docs/…`.
3. Keep the change focused and add or update tests.
4. Write commit messages in the format described in the full guide (commits are linted).
5. Open a pull request using the template and link the issue it closes (`Closes #123`).
6. Wait for the required checks and one review. Never push directly to a protected branch.
